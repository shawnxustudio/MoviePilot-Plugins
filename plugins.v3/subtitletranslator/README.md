# 字幕机翻

在 MoviePilot 里**搜索媒体库影视**，选中后把内嵌字幕机翻成中文，写回视频同目录并刷新媒体服务器。

从 [subtitle](https://github.com/shawnxustudio/subtitle)（跑在 9897 端口的 Flask 版）搬过来的「库内影视机翻」能力，改造成 MP 插件形态。

## 用法

1. 插件中心 → 已安装 → **字幕机翻** → 详情页（右上角「设置」进入配置页）
2. 默认按**入库时间倒序**列出最近 40 部（最新入库排最前），可切「电影 / 剧集」或输入片名搜索
3. 卡片上标 **需翻译** / **已有中文**、入库日期、字幕轨数量与语言
4. 点「机翻」先弹**选轨窗口**：自动（优先英文）或手动指定某条字幕轨，图形字幕会标灰
5. 确认后任务进入**队列**并在后台跑，可以关掉页面；顶部任务条显示**当前阶段**（提取字幕 → 翻译字幕 → 写入字幕 → 刷新媒体库）、当前文件、行进度、已用时和预计剩余
6. 完成后：MP 推送通知 + 页面结果条 + 卡片徽章变「已有中文」；「最近任务」里保留最近 10 次记录

不再需要填写媒体目录，也不会全盘扫描：搜索走媒体服务器（Emby）的条目接口，点谁翻谁。

## 配置

| 项 | 说明 |
| --- | --- |
| 翻译服务商 | DeepSeek / 硅基流动 / 阿里云百炼 / Kimi / 智谱 / OpenRouter / Gemini / 自定义 OpenAI 兼容；每个服务商单独记 Key，切换自动换 Key 并重拉模型 |
| API Key | 必填 |
| 模型 | 点「拉取模型」从服务商实时拉列表，下拉选择（也可手输）；没填 Key 时先给常用模型兜底 |
| 自定义接口地址 | 留空用服务商默认，反代时再填 |
| 输出模式 | 默认**双语**：一条字幕里译文在上、原文在下，写 `<名字>.zh-en.srt`；也可切「仅译文」，写 `<名字>.zh.srt` |
| 每批行数 | 一次请求翻几行，默认 20，模型弱就调小 |
| 批次间隔 | 每批之间等几秒，默认 0.5，防限流 |
| 失败重试次数 | 单批失败重试几次，默认 2；仍失败会二分重试，最后逐行，仍不行就保留原文 |
| 术语表 | 每行 `原文=译文`，统一人名地名 |
| 覆盖已有中文字幕 | 默认关，已有 `.zh.srt` 直接跳过 |

## 工作方式

1. 用媒体服务器配置里的 Emby 条目接口搜索（`IncludeItemTypes=Movie,Series`），一次带回 `Path` 和 `MediaSources`，所以卡片能直接显示有无中文字幕轨
2. 点翻译后按条目路径展开视频文件：电影取文件本身，剧集取整季目录下的所有视频
3. `ffprobe` 复核字幕轨：用户指定了轨道就用指定的那条，否则挑非中文文本轨（优先英文），再用 `ffmpeg` 转 SRT
4. 分批调大模型翻译，按 `序号|译文` 校验行数，不齐就二分重试
5. 写回字幕并请求媒体服务器刷新：双语 → `<视频名>.zh-en.srt`（译文在上、原文在下），仅译文 → `<视频名>.zh.srt`

> 与 9897 那个项目保持一致。注意 Emby 会把 `.zh-en.srt` 标成语言 `zh-en` 而不是「中文」，
> 播放器里显示为 `zh-en (SRT)`；要「中文」标签就用「仅译文」模式（写 `.zh.srt`）。

媒体服务器返回的路径和容器内挂载点常常不同（比如媒体服务器里的 `/media` 对应容器里的 `/media/library`），插件会按路径尾部自动匹配容器内真实目录，不需要额外配置。

## 任务怎么跑

- **不需要等**：确认后就是后台任务，可以关页面、关浏览器
- **队列**：连续点多部/多剧会排队，一个个跑，顶部能看到「队列 N」和排队片名
- **可停止**：任务条上的「停止」会中断当前任务并清空队列
- **状态持久化**：队列、当前进度、最近 10 次历史都存在插件数据里，页面刷新或插件重载后仍然可见；插件重载时正在跑的任务会标记为「已中断」
- **完成通知**：MP 通知渠道收到「成功 x，跳过 y，失败 z，用时 m 分 s 秒」，失败会附第一条失败原因
- **回来能看**：打开页面时若十分钟内刚跑完过任务，顶部会直接显示那次结果

## 限制

- 图形字幕（PGS / DVD sub）无法转文本，会明确提示跳过
- 剧集目前是整剧处理，没有按季/按集挑选（选轨窗口展示的是第一集的轨道，该轨道号会套用到每集）
- 同一时间只跑一个任务
- 依赖宿主的媒体服务器配置（当前按 Emby 实现，其他媒体服务器会退化成搜索不到）

## 前端

详情页和配置页都是 Vue 联邦组件（`dist/assets/remoteEntry.js`），因为 MP 的 Vuetify JSON 页面不支持输入框绑定。

```bash
cd frontend
npm install
npm run build      # 产物在 frontend/dist，复制到插件目录的 dist/
```
